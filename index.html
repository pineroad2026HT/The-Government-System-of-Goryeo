중학교 3학년 역사 수업에서 사용할 모바일 웹 기반 인터랙티브 역사 탐정 활동을 제작해줘. 웹앱 제목: 「고려 통치 미스터리 - K-史의 오류를 찾아라」 ================================================== 1. 개발 목적 ================================================== 대상: 중학교 3학년 교과: 역사 주제: 고려의 통치 제도 활동 시간: 약 10분 활동 유형: 자료 분석 + 오류 찾기 + 역사 추론 학생들은 이미 고려의 통치 제도를 학습한 상태이며, 이 웹앱은 새로운 내용을 가르치는 용도가 아니라 배운 내용을 자료와 증거를 통해 확인하는 활동이다. 학생은 '고려사 특별수사대'의 조사관 역할을 맡는다. 역사 학습 AI 'K-史'가 고려의 통치 제도를 분석했지만, 보고서에는 일부 사실만을 근거로 한 과도한 일반화와 역사적 오류가 포함되어 있다. 학생은 증거를 조사하여 AI의 판단을 검증하고 오류를 수정한다. 전체 활동의 사고 흐름: AI의 주장 → 증거 조사 → 자료 분석 → 4지선다 판단 → 피드백 → 새로운 증거 해제 → CASE SOLVED 단순 역사 용어 맞히기 게임으로 만들지 않는다. ================================================== 2. 개발 방식 ================================================== GitHub Pages에서 바로 배포할 수 있는 정적 웹앱으로 제작한다. 별도의 서버, 데이터베이스, 로그인 기능은 사용하지 않는다. HTML, CSS, Vanilla JavaScript만 사용한다. React, Vue 등의 프레임워크는 사용하지 않는다. 가능하면 다음 구조로 제작한다. / ├ index.html └ images/ ├ tang.png └ goryeo.png CSS와 JavaScript는 index.html 내부에 포함하여 관리해야 할 파일을 최소화한다. GitHub Pages에 index.html과 images 폴더만 업로드하면 바로 실행될 수 있어야 한다. 모바일, 태블릿, PC에 모두 대응하는 반응형 웹앱으로 제작한다. ================================================== 3. 디자인 ================================================== 전체 콘셉트: '고려사 특별수사대의 역사 사건 파일' 중학교 3학년 남학생을 대상으로 하므로 유아적인 캐릭터나 귀여운 게임 디자인은 피한다. 분위기: - 사건 기록 - 비밀 문서 - 수사 파일 - 증거 카드 - 조사 기록 - CASE SOLVED 도장 색상: 짙은 남색 / 차콜 / 아이보리 / 회색 계열을 중심으로 한다. 강조 요소에는 금색이나 어두운 적색을 제한적으로 사용한다. 가독성을 가장 중요하게 한다. 한 화면에 너무 많은 정보를 보여주지 않는다. 버튼은 스마트폰에서도 쉽게 누를 수 있을 정도로 크게 만든다. 지나친 애니메이션은 사용하지 않는다. CASE SOLVED 도장이나 새로운 증거 등장 정도에만 짧은 애니메이션을 사용한다. ================================================== 4. 기본 기능 ================================================== 첫 화면에는 다음 세 사건을 보여준다. [증거 조사] 증거 A 중서문하성의 낭사 "정치의 잘못을 비판하고 왕에게 의견을 제시하였다." 증거 B 어사대의 관리 "관리의 잘못을 감찰하였다." 질문: "두 집단의 관리들을 함께 묶어 부른 명칭으로 가장 적절한 것은?" ① 중추원 ② 대간 ③ 삼사 ④ 도병마사 정답: ② 정답 피드백: "중서문하성의 낭사와 어사대의 관리를 함께 대간이라 하였습니다. 대간은 관리의 잘못을 감찰하고 정치의 잘못을 비판하는 역할을 하였습니다." GitHub Pages에서 HTTPS 정적 사이트로 정상 작동해야 한다. 15. 코드에는 교사가 수정하기 쉽도록 CASE 01, CASE 02, CASE 03 등의 주석을 충분히 작성한다. 16. JavaScript 오류로 한 문제가 작동하지 않아도 전체 페이지가 흰 화면이 되지 않도록 한다. 17. 모바일 Safari와 Chrome에서 정상 작동하도록 한다. 18. 브라우저 뒤로가기 버튼에 의존하지 않는다. 웹앱 내부 버튼으로 이동하게 한다. 19. 현재 사건의 증거를 다시 볼 수 있는 [증거 다시 보기] 기능을 제공한다. 20. 완성 후 코드 전체를 스스로 점검하여 깨진 버튼, 이동할 수 없는 화면, 정답 후 다음 버튼이 나타나지 않는 문제, 모바일 화면 넘침 문제가 없는지 확인한다. ================================================== 12. 최종 출력 ================================================== 설명만 하지 말고 실제로 실행 가능한 완성 코드를 작성한다. 최종 결과물은 index.html 하나를 중심으로 작성한다. 교사가 해야 할 일은 최대한 단순하게 한다. 1.
